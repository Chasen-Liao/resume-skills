## 二、配色选择策略

每个风格均提供 A/B/C 三套经过对比度调校的独立配色方案，**未明确指定时默认选 A**。

| 配色 | 适用场景与调性 |
|------|----------------|
| **A** | **默认首选**：最经典、最通用、容错率最高的基础配色 |
| **B** | **行业偏向**：偏暖/偏冷/偏绿/偏深，针对特定行业氛围优化 |
| **C** | **个性表达**：色彩对比更柔和或更具张力，满足候选人个性化诉求 |

## 三、HTML 简历生成流程

1. **引入基础排版**：读取 `css/common.md`，将通用排版 CSS 写入 HTML `<style>`。
2. **注入风格变量与规则**：读取对应风格文件 `css/<style>.md`：
   - 提取选定配色方案（默认 A）的 CSS 变量块注入 `:root`；
   - 引入字体 Google Fonts `@import`（如使用）并写入风格特有 CSS。
3. **组件结构权威参考**：各风格 CSS 详细程度不同，**必须以 `examples/<style>.html` 为组件结构与类名的权威参考**（如 `.item-block`、`.skill-badge`、双栏结构等）。
4. **单页强约束与视觉门槛**：严格遵从 delivery-gate 验收规则（单页、≥98% 饱满度、9mm 底部安全边距）。

## 四、字体原则与搭配速查

### 字体设计原则
- **拒绝通用 AI 审美**：避免无目的堆砌 Inter、Roboto、Arial 等泛用无衬线体；同时在 Chromium PDF 导出中避免使用可变 Google 字体与触发 `Type3` / 康熙部首 / `U+2212` 的字体，统一选用已验证可嵌入 `Type0` CID 字体的静态 TrueType 字体栈。
- **中文回退安全网**：中文简历始终包含系统安全回退字体：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`（避免回退至 `Noto Serif SC`、`DengXian` 或 `NSimSun` 触发康熙部首或合成粗体 Type3）；所有英文与等宽 `font-family` 也必须显式附带中文回退。
- **字重实有原则**：字体声明仅使用该字体族实际存在的字重（例如 `Bebas Neue` 仅有 `400`，禁止设为 `700`/`900`）。
- **字阶清晰对比**：建立严格的层次阶梯：`姓名 > 板块标题 > 公司/学校/职位名 > 正文 > 辅助信息/时间`。
- **字体加载性能**：优先系统字体栈；追求高质感时使用风格文件中的静态字重 Google Fonts 引入。

### 推荐搭配速查

| 风格方向 | 标题字体 | 正文字体 | 调性与场景 |
|----------|----------|----------|------------|
| 经典商务 | Fira Sans / Lato | Fira Sans | 高端稳重、专业信赖 |
| 现代专业 | Poppins / Fira Sans | Fira Sans / Lato | 清晰现代、高可读性 |
| 科技前沿 | Barlow / IBM Plex Mono | Fira Sans / IBM Plex Mono | 极客硬核、结构严谨 |
| 创意活力 | Bebas Neue (400) / Barlow | Fira Sans | 个性鲜明、视觉先锋 |
| 东方雅致 | Spectral / Georgia | Fira Sans | 空灵留白、人文温度 |

> 以各风格 `css/<style>.md` 与对应 `examples/<style>.html` 中的设定为准，上表供调整扩展参考。

## 五、设计美学要点

### 1. 扫描效率第一
HR 与面试官在 6-15 秒内完成初筛，排版必须服务于视线流（视觉锚点、公司职位、关键量化指标加粗）。

### 2. 基调极致执行
选定极简、商务、创意或科技感等基调后极致执行，杜绝拼贴感与平庸折中。

### 3. 色彩与视觉细节
- **主色 + 锐利点缀色** > 软弱均匀的调色板；杜绝俗套的紫蓝渐变配纯白底。
- 微妙的背景氛围（底色微调、细线分割、精密边框、色块分区），打印时 `@media print` 简化但不破坏结构。

### 4. 空间与布局节奏
- 内容丰富推荐左右双栏（左侧窄栏放置基本信息、技能、教育；右侧主栏展开经历与核心项目）；经历聚焦推荐经典单栏。
- 严禁文本孤行 (`orphans: 2; widows: 2;`)，谨慎使用过激的局部防断裂。
- 实现复杂度匹配美学愿景：极简需克制精准，优雅源自执行到位，而非样式堆砌。
