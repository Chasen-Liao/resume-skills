# Canvas 预览端：AI 生成后的最后小修小补

> 一句话定位：AI 帮你生成简历 HTML 之后，往往只需要一些小修小补——改一个错别字、微调字号或对齐。不必为这些小事重走一遍 Agent 工作流，打开本地 Web 预览端，改完直接保存回本地 HTML，再导出 PDF 即可。

## 闭环长什么样

```text
AI 生成 HTML → 打开 Web 预览端 → 小修小补 → 保存到本地 → 导出 PDF
```

每一步的具体做法见下文。整个过程不需要联网，简历数据只在本机流转。

## 什么时候用它

- 改了联系方式、错别字或措辞，不想为一行字重新生成整份简历
- 微调字号、对齐、颜色、行高、页边距，让版面更舒服
- 投递前快速确认页面没有垂直溢出

它适合**小改**。要换结构、补经历或做 JD 定制，请回到 Agent 工作流（`resume-builder` / `jd-tailorer`）。

## 前置条件

- 已经生成**视觉版** HTML（内置模板自带编辑协议，天然满足）
- 本机已安装 Node.js 20 或更高版本
- ATS-safe 单栏版、外部模板和手写 HTML 不一定能被预览端打开

## 1. 启动预览端

在简历文件所在目录执行：

```bash
npx -p @chasen-liao/resume-skills@latest resume-skills editor resume_visual.html
```

- 编辑器会启动本机服务（默认 `127.0.0.1:8848`）并尝试自动打开浏览器
- 启动前自动校验编辑协议：模板、版本、至少一个叶子文本字段的编辑 ID 都必须有效；不合格会直接报错并给出 `rg -n` 定位命令，不会启动服务
- 端口 8848 被占用时自动顺延到 8853，仍不可用则回退随机端口；想固定端口用 `--port <number>`（显式指定时为严格模式，占用即报错）

启动后界面分三块：左侧是保存/打印按钮和溢出提示，中间是 A4 简历画布，右侧是排版面板。

## 2. 小修小补

### 改文字

在中间的 A4 画布上**单击**一段文字即选中并可输入（仅纯文本，中文输入法可用），**双击**同样进入编辑；也可以在左侧"文字内容"框里直接改写。

- `Tab` / 方向键在字段间移动焦点，`Enter` / `空格` 进入编辑
- `Ctrl/Cmd+Enter` 或点击别处完成编辑，`Esc` 撤销本次修改

### 调排版

选中文字后，在右侧"排版"面板调整字号、字重、颜色、对齐、行高和段后间距；页面级设置可以调整页边距和主题色。所有修改实时反映在画布上。

### 检查页面状态

左侧会显示 A4 垂直溢出提示。出现溢出时，先回到内容或排版流程删减调整，**不要把字号压缩到难以阅读**。

## 3. 保存到本地

点击左侧"**保存修改**"，排版和文字改动会原子写回原始 HTML（先写临时文件再替换，并保留一个 `.bak` 备份）：

- 同名前缀的 PDF manifest 会自动失效——旧 PDF 不再被当成对应当前 HTML，**保存后必须重新渲染并验证 PDF**
- 未保存的草稿会留在当前浏览器中；关闭页面前请先保存
- 源文件被外部或 Agent 更新时，预览端会自动热重载（Live Preview）

## 4. 导出 PDF

点击"**打印为 PDF**"，在浏览器打印面板中选择 A4，按需关闭浏览器默认的页眉和页脚后保存。若浏览器没有自动打开，直接打开终端中显示的本地地址即可。

## 能做什么 / 不能做什么

**能**：编辑已有字段的纯文本；调整字号、字重、颜色、对齐、行高、段后距、页边距和主题色。

**不能**：

- 新增字段、插入 HTML、结构重排、自由拖拽或图片编辑
- AI 改写、自动补充经历、JD 分析和关键词匹配
- 打开 ATS-safe 单栏模板

文字事实的修改记得在投递前回到 Agent 工作流确认，避免未核验内容进入最终交付。

## 安全边界

预览端默认只监听本机回环地址（`127.0.0.1` / `::1`），**不会**绑定到局域网或公网，同网段其他设备无法访问你的简历。

它还会做几层防御：

- 打开前校验编辑协议；保存时服务端重新校验：结构保持不变、只能改已有文字与受限排版项
- 简历 HTML 在禁脚本的 iframe 沙箱中加载，里面的 `<script>` 不会执行
- 保存带版本号防冲突，原子写 + 备份防写坏原文件
- 资产读取限制在简历同目录内，越界请求返回 403
